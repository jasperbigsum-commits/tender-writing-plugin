# OpenAI 公共插件设计与待验证边界

核对日期：2026-11-17。候选版本：0.1.3，未发布、未提交商店。

## 架构选择

采用 Agent Plugins 1.0 根 `plugin.json`，保留六个 `skills/*/SKILL.md` 与本地文件工具。OpenAI 展示和审核元数据归入 `extensions.com.openai`。保留 `.codex-plugin/plugin.json` 兼容清单，完整同步名称、版本与展示字段；保留 Claude 兼容入口。

本包不连接远端服务，不需要为“插件”这个名字虚构 MCP 服务器、OAuth、旧版 `ai-plugin.json` 或 OpenAPI 接口。公共插件目录面向 ChatGPT 与 Codex；本地市场安装成功与公共目录审核通过是不同结果。具体宿主是否支持脚本执行、Python 文档依赖和文件访问，必须实际安装验证，不能仅凭 JSON 判定所有平台兼容。

仓库市场使用 `.agents/plugins/marketplace.json`，原 `.claude-plugin/marketplace.json` 保留为一致的兼容镜像。源码市场不进入单插件 ZIP。当前展示名称与中文起始提示保持不变，未凭空编写发布者身份。

## 本轮实现

- 原 SVG 品牌图标无设计改动地渲染为 512×512 PNG，根与 Codex 清单均引用 PNG。
- 增加真实任务的 review.prompts 和候选版本 release_notes；不声明工具调用或商业功能。
- 构建检查完整兼容展示字段及市场镜像，检查实际 ZIP 中的隐藏清单、应用绑定、单根目录、安全路径、PNG 与提示词。
- 单独生成 `dist/public-readiness.json`，明确本地结构检查不等于官方完整 schema 校验、安全扫描或上架审核。
- 业务技能、文件工具与 RSI 评测器未改动；RSI 仍只在完整源码中，不进入安装包。

## 桌面本地执行要求（2026-11-17 补核）

主要文件工作流需要执行包内 Python 脚本、读取/写入项目文件并导出 Word/PDF，故此纯技能插件依赖本地执行器。根清单 `extensions.com.openai.requires_local_executor` 与 Codex 兼容清单顶层 `requires_local_executor` 均明确设为 `true`，按官方桌面专用规范声明，不新增 MCP。
