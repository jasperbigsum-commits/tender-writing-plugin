# v0.1.2：有界可信候选评测器

新增仓库级 `tools/rsi_loop.py`：固定目标评测、最多候选轮次、超时、失败回退与记录。

- 冻结所有目标夹具与基线依赖，检测内容、增删与符号链接污染。
- 每次评估使用独立临时目录；修复超时、中断及退出时的进程组清理。
- 70 项本地回归及实际仓库基线验证通过。
- 不调用模型、不运行后台任务，不自动生成或发布代码。

## 限制与安全边界

仅运行已经审阅的可信候选。它不是恶意代码沙箱，没有文件系统、网络、内存和磁盘强隔离；不能防御主动脱离进程组的代码。测试通过不代表真实标书质量，未完成此次 DOCX 视觉复核。独立的 audit/matrix 符号链接防护不在本发布范围。

单插件 ZIP 提供写作技能；仓库级评测器请使用 GitHub 完整源码包。此版本没有自动安装或更新用户电脑中的插件。
