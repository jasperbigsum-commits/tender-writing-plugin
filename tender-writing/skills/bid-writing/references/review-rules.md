# 九类基础检查与专项复核

这九类是本插件自行定义的可解释检查，参考百炼公开页面的风险扫描思路；页面没有披露完整规则实现。不要把这些规则宣称为其官方规则库。

| 类别 | 脚本实际检查 | 仍需实际复核 |
| --- | --- | --- |
| coverage 要求完整性 | 空台账、未映射要求、缺正文、孤立章节、待填项、目录循环 | 要求是否漏抽、附件是否齐全、全文实质覆盖 |
| qualification 资格证据 | 主体、状态、有效期、资格项缺证明 | 证书真伪、适用范围、人员及业绩是否满足 |
| consistency 关键字段 | 主体/标包、正文申报的 field_values 与主数据 | 全文全部姓名、日期、编号、金额和承诺 |
| response 响应与偏离 | 状态、主响应章节、正文存在、章节审阅状态 | 参数和商务承诺是否实质满足，是否隐含偏离 |
| scoring 评分项落实 | 评分项的关联和过短正文提示 | 评分证据及方案是否有针对性，不自动授分 |
| format 格式与暗标 | 已知身份词、专项复核记录 | 真正字体、分页、图表、制式表格、元数据及签章 |
| price 报价基础运算 | 非负有限数、分项乘积、合计、预算和币种 | 税率、计价口径、价格合理性及特殊公式 |
| traceability 原文可追溯 | 文件哈希、引用角色、定位及逐字摘录匹配 | 摘录上下文、OCR精度、事实推断是否成立 |
| similarity 相似线索 | 同一正文内长度至少80字符的章节两两比较，SequenceMatcher比率至少0.85提示 | 跨文件比对、公共条款扣除、图片变体和相似原因 |

基础规则通过不等于实质满足。审查不得对未经核验的扫描签章、CA证书或线下提交事项给出肯定结论。全文没读完需列未审范围；基础运算与规则定位也不能替代正式评标、法律或财务意见。

## 专项复核记录

- semantic：全部适用要求与正文及证明的实质比对，保留发现和未解决问题。
- format：对招标模板和最新渲染结果逐页核对。没有渲染不能只凭 XML 说版式通过。
- signature：实际签章、签字、授权及附件的核对。草稿尚未签章时记录 issue 或保留未完成；若此阶段确实不适用可说明原因。
- similarity：说明本次比较的文件、文本/图像方法和公共内容范围。只做内部重复检查时如实说明，不能冒充跨投标人查重。

记录可以由实际执行检查的模型或人员形成，必须准确标明是谁做了什么。需要第三方或专家动作时列入清单，不虚构其批准。导出后修改 Word 产生新版本，应重新登记内容、复核与回执，而非沿用旧文件哈希。
